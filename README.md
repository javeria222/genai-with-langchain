# Project Name

A conversational AI app built with **LangChain**, **Streamlit**, and the **Groq API** for fast LLM inference.

## Features

- Chat interface powered by Streamlit
- LLM responses via Groq's low-latency inference
- LangChain for prompt orchestration / chaining

## Key takeaways and problems we tackled:
*Connecting an LLM with an API key and handling responses.
*Integrating the GroqChat API to run the Llama-3.3-70B model for fast and efficient responses.
*Designing an interactive Streamlit interface for both static and dynamic input.
*Building a chatbot and fixing an early challenge where it couldn’t remember previous answers when moving to the next question.
